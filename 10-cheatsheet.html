核心公式

定义 · 时域

$$\hat{x}(t)=\mathcal{H}\{x\}(t)=\frac{1}{\pi}\,\mathrm{P}\!\!\int_{-\infty}^{\infty}\frac{x(\tau)}{t-\tau}\,\mathrm{d}\tau=\frac{1}{\pi t}*x(t)$$

定义 · 频域

$$\hat{X}(\omega)=-j\,\mathrm{sgn}(\omega)\,X(\omega),\qquad |H|=1,\ \ \arg H=\mp\tfrac{\pi}{2}$$

解析信号

$$z(t)=x(t)+j\hat{x}(t)=A(t)e^{j\phi(t)},\qquad Z(\omega)=2X(\omega)\,u(\omega)$$

三个瞬时量

$$A=\sqrt{x^2+\hat{x}^2},\qquad \phi=\operatorname{atan2}(\hat{x},x),\qquad \omega_i=\dot\phi=\frac{x\dot{\hat x}-\hat x\dot x}{x^2+\hat x^2}$$

无奇点的等价写法

$$\hat{x}(t)=\frac{1}{\pi}\int_{0}^{\infty}\frac{x(t-u)-x(t+u)}{u}\,\mathrm{d}u$$

性质总表

#性质表达式前提
1线性$\mathcal{H}\{ax+by\}=a\hat{x}+b\hat{y}$—
2时移不变$\mathcal{H}\{x(t-t_0)\}=\hat{x}(t-t_0)$—
3尺度$\mathcal{H}\{x(at)\}=\mathrm{sgn}(a)\,\hat{x}(at)$$a\neq0$
4二次迭代$\mathcal{H}^2=-I$，$\mathcal{H}^4=I$，$\mathcal{H}^{-1}=-\mathcal{H}$零均值
5保能量$\lVert\hat{x}\rVert_2=\lVert x\rVert_2$零均值
6正交 / 反自伴$\int x\hat{x}\,\mathrm{d}t=0$；$\langle\mathcal{H}x,y\rangle=-\langle x,\mathcal{H}y\rangle$$x,y$ 实
7奇偶反转偶 $\to$ 奇，奇 $\to$ 偶—
8与微分交换$\mathcal{H}\{x'\}=(\hat{x})'$—
9卷积$\mathcal{H}\{x*y\}=\hat{x}*y=x*\hat{y}$；$\hat{x}*\hat{y}=-x*y$—
10Bedrosian$\mathcal{H}\{fg\}=f\,\hat{g}$频带分离
11直流消失$\hat{X}(0)=0$，$\int\hat{x}\,\mathrm{d}t=0$—
12Titchmarsh希尔伯特关系 $\iff$ 单边谱 $\iff$ 上半平面解析$L^2$
—不成立$\mathcal{H}\{xy\}\neq x\hat{y}$（除非满足 Bedrosian）—

算法与代码

FFT 法（五步）
  1. 去直流：$x\leftarrow x-\bar{x}$
  2. $X=\mathrm{FFT}(x)$
  3. 权重：$h[0]=1$；$h[k]=2$（$1\le k<N/2$）；$h[N/2]=1$（$N$ 偶）；$h[k]=0$（$k>N/2$）
  4. $Z=hX$
  5. $z=\mathrm{IFFT}(Z)$，则 $\hat{x}=\operatorname{Im}z$，且应有 $\operatorname{Re}z=x$（自检）
离散理想冲激响应

$$h[n]=\frac{1-\cos\pi n}{\pi n}=\begin{cases}\dfrac{2}{\pi n},&n\ \text{奇}\\[4pt]0,&n\ \text{偶（含 }n=0\text{）}\end{cases}$$

奇对称、非因果、$1/n$ 慢衰减。FIR 半长经验值 $M\gtrsim\frac{f_s}{2f_{\min}}\times(3{\sim}5)$，群延时 $M$ 个采样。

# ============ 常用片段 ============
import numpy as np
from scipy.signal import hilbert, butter, filtfilt, get_window, remez, lfilter

# 解析信号 / 希尔伯特变换 / 包络
z   = hilbert(x - x.mean())    # ⚠ 返回复数：解析信号，不是 H{x}
xh  = z.imag                   # 希尔伯特变换
env = np.abs(z)               # 瞬时幅度（包络）

# 瞬时频率（微分公式，免相位解缠，推荐）

fi = np.imag(np.conj(z)*dz) / (np.abs(z)**2 + 1e-20) / (2*np.pi)
# ⚠ 中心差分把 f_i 低估 sinc(2f_i/fs) 倍；每周期 < 20 点时须修正：
fi = fi / np.sinc(2*fi/fs)      # np.sinc(a)=sin(πa)/(πa)，故系数是 2 不是 1

# 瞬时频率（解缠法，噪声大时会灾难性失败）
fi2 = np.gradient(np.unwrap(np.angle(z))) * fs / (2*np.pi)

# 镜像延拓，压制端点效应
xe = np.concatenate([x[::-1], x, x[::-1]])
z  = hilbert(xe)[len(x):2*len(x)]

# 包络谱（轴承 / 齿轮诊断）
b,a = butter(4, [2000/(fs/2), 6000/(fs/2)], 'band')
env = np.abs(hilbert(filtfilt(b, a, x - x.mean())))
env = env - env.mean()                       # ⚠ 包络也要去直流
sp  = np.abs(np.fft.rfft(env * get_window('hann', len(env))))
fq  = np.fft.rfftfreq(len(env), 1/fs)

# 实时 FIR 希尔伯特变换器（务必配对延时！）
h  = remez(65, [0.03, 0.47], [1], type='hilbert', fs=1.0)

实用检查清单

拿到实测数据求包络 / 瞬时频率，按顺序做这七步
  1. 去直流　减均值。防止包络被偏置污染。
  2. 看频谱，数峰　多个峰 → 必须先分解（带通 / 小波 / EMD），否则瞬时频率无意义。
  3. 带通到单分量　用 filtfilt（零相位）。检查相对带宽 $B/f_0<0.5$。
  4. 镜像延拓　抑制端点效应。
  5. 求解析信号　hilbert()，记得取 .imag 或 abs()。
  6. 瞬时频率用微分公式　避开相位解缠。
  7. 丢弃两端各 10%　这部分结果不可信。

另外确认采样率：相位解缠需每周期 ≥ 8 点；若要定量使用瞬时频率，需每周期 ≥ 20 点 —— 中心差分会把 $\omega_i$ 低估 $\mathrm{sinc}(\omega_i\Delta t)$ 倍（8 点时低估 10%，20 点时 1.6%）。奈奎斯特的 $2f_{\max}$ 远远不够。

七个必踩的坑
#坑症状
1hilbert(x) 当成 $\hat{x}$结果是复数；包络、相位全错
2忘记去直流包络整体抬高、相位失真
3端点效应两端包络隆起 / 凹陷；包络谱底噪抬高
4对多分量求瞬时频率$f_i$ 剧烈振荡、出现负值
5FIR 未配对延时包络"差不多"但相位有系统偏差
6采样率过低解缠解错方向；且 $f_i$ 被 $\mathrm{sinc}$ 系统性低估
7奈奎斯特权重写错$\operatorname{Re}z\neq x$，出现正负交替涟漪

三条应用主线

主线用的性质代表应用关键前提
① 单边谱$Z(\omega)=2X(\omega)u(\omega)$SSB、I/Q 调制、音频频移、镜像抑制$f_c>$ 基带带宽
② 瞬时属性$A=\lvert z\rvert$，$\omega_i=\dot\phi$包络检波、轴承诊断、地震属性、EEG 同步、阻尼识别单分量 + 窄带
③ 因果性实部 $\leftrightarrow$ 虚部互为 $\mathcal{H}$Kramers–Kronig、Bode 增益-相位、最小相位系统线性 + 因果 + 稳定

常用工程公式

SSB 调制

$$s_{\text{USB}}=m\cos\omega_ct-\hat{m}\sin\omega_ct$$

$$s_{\text{LSB}}=m\cos\omega_ct+\hat{m}\sin\omega_ct$$

相位锁定值（PLV）

$$\mathrm{PLV}=\left|\frac{1}{N}\sum_n e^{j[\phi_1(t_n)-\phi_2(t_n)]}\right|$$

无同步时的有限样本偏差 $\approx0.886/\sqrt{N}$。

轴承特征频率

$\mathrm{BPFO}=\frac{n}{2}f_r\!\left(1-\frac{d}{D}\cos\alpha\right)$
$\mathrm{BPFI}=\frac{n}{2}f_r\!\left(1+\frac{d}{D}\cos\alpha\right)$
$\mathrm{BSF}=\frac{D}{2d}f_r\!\left[1-\left(\frac{d}{D}\cos\alpha\right)^2\right]$
$\mathrm{FTF}=\frac{1}{2}f_r\!\left(1-\frac{d}{D}\cos\alpha\right)$

实测通常比理论值低 1%～2%（滚珠滑移）。内圈故障常伴 $f_r$ 间隔的边带。

Kramers–Kronig

$$\chi'(\omega)=\frac{2}{\pi}\mathrm{P}\!\!\int_0^\infty\frac{\omega'\chi''(\omega')}{\omega'^2-\omega^2}\mathrm{d}\omega'$$

无吸收 $\Rightarrow$ 无色散，反之亦然。

Bode 增益-相位（近似）

$$\arg H\approx\frac{\text{斜率 (dB/dec)}}{20}\times90°$$

穿越频率附近取 $-20$ dB/dec（相位裕度 $90°$）。$-40$ dB/dec $\Rightarrow$ 裕度 $\approx0$。

线性 chirp

$$x=\cos\!\big(2\pi(f_0t+\tfrac{k}{2}t^2)\big)$$

$$f_i(t)=f_0+kt$$

一句话总结全书

希尔伯特变换是一台把每个频率成分的相位转 $90°$、幅度分毫不动的机器。
它在时域是与 $\frac{1}{\pi t}$ 的卷积，在频域是乘 $-j\,\mathrm{sgn}(\omega)$。
它最大的用处是给实信号配一个"虚部搭档"，凑成只含正频率的解析信号，
从而让"此刻的幅度"和"此刻的频率"第一次有了唯一、可计算的定义。
而它一切应用的合法性，都系在"单分量 + 窄带"这一个前提上。
