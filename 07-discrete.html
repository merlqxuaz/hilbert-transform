第 7 章

在计算机上怎么算

从理想积分式到能跑的代码。两条路线（FFT 与 FIR）、完整代码、以及七个会让你的结果悄悄出错的坑。

7.1 问题的转化

实际数据总是离散采样的：$x[n]=x(nT_s)$，$n=0,1,\dots,N-1$，采样频率 $f_s=1/T_s$。离散时间信号的频率范围被限制在 $\omega\in(-\pi,\pi]$（数字角频率，对应 $-f_s/2$ 到 $f_s/2$）。所以我们要的频率响应是

$$H(e^{j\omega})=-j\,\mathrm{sgn}(\omega),\qquad -\pi<\omega\le\pi$$

对它做离散时间傅里叶逆变换，得到理想离散冲激响应：

离散希尔伯特变换器的理想冲激响应

$$h[n]=\frac{1}{2\pi}\int_{-\pi}^{\pi}\!\!-j\,\mathrm{sgn}(\omega)\,e^{j\omega n}\,\mathrm{d}\omega=\frac{1-\cos(\pi n)}{\pi n}=\begin{cases}\dfrac{2}{\pi n},&n\ \text{为奇数}\\[6pt]0,&n\ \text{为偶数（含}\,n=0\,\text{）}\end{cases}$$

这个积分不难，但每一步都值得写清楚 —— 后面 FIR 设计的所有系数都从它来。

推导 · 从 $H(e^{j\omega})=-j\,\mathrm{sgn}(\omega)$ 到 $h[n]$

第一步 · 写出逆变换式，并按 $\mathrm{sgn}$ 的分段把积分断开。

离散时间傅里叶逆变换的定义是 $h[n]=\frac{1}{2\pi}\int_{-\pi}^{\pi}H(e^{j\omega})e^{j\omega n}\,\mathrm{d}\omega$。代入 $H=-j\,\mathrm{sgn}(\omega)$。因为 $\mathrm{sgn}(\omega)$ 在 $\omega>0$ 上等于 $+1$、在 $\omega<0$ 上等于 $-1$，不是一个统一的表达式，所以要在 $\omega=0$ 处把积分区间断成两段：

$$h[n]=\frac{-j}{2\pi}\left[\int_{0}^{\pi}(+1)\,e^{j\omega n}\,\mathrm{d}\omega+\int_{-\pi}^{0}(-1)\,e^{j\omega n}\,\mathrm{d}\omega\right] =\frac{-j}{2\pi}\left[\int_{0}^{\pi}e^{j\omega n}\,\mathrm{d}\omega-\int_{-\pi}^{0}e^{j\omega n}\,\mathrm{d}\omega\right]$$

第二步 · 分别算这两个基本积分（先设 $n\neq0$）。

$e^{j\omega n}$ 关于 $\omega$ 的原函数是 $\dfrac{e^{j\omega n}}{jn}$（求导验证：$\frac{\mathrm{d}}{\mathrm{d}\omega}\frac{e^{j\omega n}}{jn}=\frac{jn\,e^{j\omega n}}{jn}=e^{j\omega n}$ ✓）。逐个代上下限：

$$\int_{0}^{\pi}e^{j\omega n}\,\mathrm{d}\omega=\left[\frac{e^{j\omega n}}{jn}\right]_{0}^{\pi}=\frac{e^{j\pi n}-1}{jn}$$

$$\int_{-\pi}^{0}e^{j\omega n}\,\mathrm{d}\omega=\left[\frac{e^{j\omega n}}{jn}\right]_{-\pi}^{0}=\frac{1-e^{-j\pi n}}{jn}$$

第三步 · 相减，并用欧拉公式把两个复指数并成余弦。

$$\int_{0}^{\pi}-\int_{-\pi}^{0}=\frac{e^{j\pi n}-1}{jn}-\frac{1-e^{-j\pi n}}{jn}=\frac{\big(e^{j\pi n}-1\big)-\big(1-e^{-j\pi n}\big)}{jn}=\frac{e^{j\pi n}+e^{-j\pi n}-2}{jn}$$

由欧拉反公式 $e^{j\theta}+e^{-j\theta}=2\cos\theta$（第 2.1.2 节），分子等于 $2\cos(\pi n)-2$，于是

$$\int_{0}^{\pi}-\int_{-\pi}^{0}=\frac{2\big(\cos\pi n-1\big)}{jn}$$

第四步 · 乘回前面的 $\frac{-j}{2\pi}$。

注意 $\dfrac{-j}{j}=-1$，两个虚数单位约掉，结果自动变成实数（本该如此：$h[n]$ 是实滤波器的系数）：

$$h[n]=\frac{-j}{2\pi}\cdot\frac{2\big(\cos\pi n-1\big)}{jn}=\frac{-\big(\cos\pi n-1\big)}{\pi n}=\boxed{\frac{1-\cos(\pi n)}{\pi n}}$$

第五步 · 化成分段形式。

对整数 $n$ 有 $\cos(\pi n)=(-1)^n$，于是分子只有两种取值：

  • $n$ 为偶数：$\cos\pi n=+1$，分子 $1-1=0$，故 $h[n]=0$。
  • $n$ 为奇数：$\cos\pi n=-1$，分子 $1-(-1)=2$，故 $h[n]=\dfrac{2}{\pi n}$。

补上 $n=0$ 这一点。第二步里除以了 $n$，所以 $n=0$ 必须单独算。直接回到第一步，此时 $e^{j\omega\cdot 0}=1$，两个积分都只是区间长度：

$$h[0]=\frac{-j}{2\pi}\left[\int_0^\pi 1\,\mathrm{d}\omega-\int_{-\pi}^0 1\,\mathrm{d}\omega\right]=\frac{-j}{2\pi}\big[\pi-\pi\big]=0$$

和"偶数位置为零"的规律一致。（也可以对 $\frac{1-\cos\pi n}{\pi n}$ 取 $n\to0$ 的极限：分子 $1-\cos\pi n\approx\frac{(\pi n)^2}{2}$，整体 $\approx\frac{\pi n}{2}\to0$，同样得 $0$。）

这一步的关键直觉：$h[0]=0$ 说明"当前这一个采样点对输出毫无贡献"，输出完全由周围样本的左右差构成。这就是第 3.2 节"测量左右不对称性"在离散世界里的写照 —— 一个信号在某点的 90° 相移，跟它在那一点的值无关。

这个序列有三个特征，完全对应连续情形（第 3.3 节）：奇对称（$h[-n]=-h[n]$）、双边无限长（非因果）、$1/n$ 慢衰减。另外还多了一条有趣的：偶数位置全为零，这意味着实际滤波时只需一半的乘法，是个免费的效率红利。

7.2 路线一：FFT 法（首选）

第 6.2 节已经给出了原理。这里写成可以直接照抄的步骤。

算法 7.1 · FFT 法求解析信号

输入实序列 $x[0..N-1]$，输出复序列 $z[0..N-1]$：

  1. 去直流：$x[n]\leftarrow x[n]-\bar{x}$。（可选但强烈建议）
  2. FFT：$X[k]=\mathrm{FFT}(x)$，$k=0,\dots,N-1$。
  3. 构造单边化权重 $h[k]$：
    • $h[0]=1$（直流保持）
    • $h[k]=2$，$1\le k<N/2$（正频率翻倍）
    • $h[N/2]=1$（$N$ 为偶数时的奈奎斯特点，保持）
    • $h[k]=0$，$k>N/2$（负频率置零）
  4. 加权：$Z[k]=h[k]\,X[k]$。
  5. IFFT：$z[n]=\mathrm{IFFT}(Z)$。

则 $\operatorname{Re}z[n]=x[n]$（应当如此，可用来自检），$\operatorname{Im}z[n]=\hat{x}[n]$。

复杂度 $O(N\log N)$，是"整段数据一次性处理"的最优方案。

7.2.1 Python 代码

import numpy as np
from scipy.signal import hilbert

# ---------- 方式 A：直接用 SciPy（推荐） ----------
z = hilbert(x)            # 注意！返回的是【解析信号】 x + j*H{x}
xh = np.imag(z)           # 这才是希尔伯特变换
env = np.abs(z)           # 瞬时幅度（包络）
phi = np.unwrap(np.angle(z))
fi = np.gradient(phi) * fs / (2*np.pi)   # 瞬时频率 (Hz)

# ---------- 方式 B：自己实现，看清每一步 ----------
def analytic_fft(x):
    x = np.asarray(x, dtype=float)
    x = x - x.mean()                # 步骤 1：去直流
    N = len(x)
    X = np.fft.fft(x)               # 步骤 2
    h = np.zeros(N)                 # 步骤 3
    if N % 2 == 0:
        h[0] = h[N//2] = 1
        h[1:N//2] = 2
    else:
        h[0] = 1
        h[1:(N+1)//2] = 2
    return np.fft.ifft(X * h)       # 步骤 4、5

# 自检：实部应当还原原信号（去直流后）
z2 = analytic_fft(x)
assert np.allclose(z2.real, x - x.mean(), atol=1e-10)

最常见的一个错误

MATLAB 和 SciPy 的 hilbert() 都不返回希尔伯特变换，它们返回解析信号。忘了取虚部而直接把 hilbert(x) 当成 $\hat{x}$ 用，是初学者最高频的 bug。函数名是历史遗留，改不了了。

记忆办法：hilbert(x) 的结果是复数。如果你拿到一个复数却当实数用，一定错了。

7.3 路线二：FIR 滤波器（实时场合）

FFT 法必须等整段数据到齐，做不了实时处理。实时系统的办法是用有限长的 FIR 滤波器逼近理想的 $h[n]$。

7.3.1 设计思路：截断 + 加窗 + 延时

  1. 截断：只保留 $|n|\le M$ 的那些系数，共 $N=2M+1$ 个。
  2. 加窗：直接截断会造成吉布斯振荡，所以乘一个平滑窗（Hamming、Kaiser、Blackman）：$h_w[n]=h[n]\cdot w[n]$。
  3. 平移：把 $n\in[-M,M]$ 平移到 $n\in[0,2M]$，使滤波器变得因果。代价是引入群延时 $M$ 个采样。
配对延时：必须记住的一步

FIR 希尔伯特变换器输出的 $\hat{x}$ 比输入晚了 $M$ 个采样。所以在构造解析信号 $z=x+j\hat{x}$ 时，必须把原信号 $x$ 也延时 $M$ 个采样，否则实部和虚部对不齐，包络和相位全错：

xh = lfilter(h_fir, 1, x)      # 已经延时了 M
xd = np.concatenate([np.zeros(M), x])[:len(x)]   # 原信号也延时 M
z  = xd + 1j*xh                # 现在才对齐

这个坑非常隐蔽：不对齐时包络看起来"差不多"，但相位和瞬时频率会有系统性偏差。

7.3.2 两种类型：奇数长还是偶数长

FIR 滤波器按对称性分四类，希尔伯特变换器需要反对称（$h[n]=-h[N-1-n]$），因此只能是 Type III 或 Type IV：

类型长度 $N$零点位置延时评价
Type III奇数$\omega=0$ 和 $\omega=\pi$整数个采样直流和奈奎斯特都失真，通带较窄
Type IV偶数仅 $\omega=0$半个采样（非整数）通带更宽，但延时是半采样，对齐麻烦

表里这两行"零点位置"不用死记，两行算式就能推出来。设滤波器长 $N$、反对称 $h[n]=-h[N-1-n]$，其频率响应按定义是 $H(e^{j\omega})=\sum_{n=0}^{N-1}h[n]e^{-j\omega n}$。

推导 · 为什么零点必然落在 $\omega=0$，以及 Type III 为什么在 $\omega=\pi$ 也为零

在 $\omega=0$ 处（对两种类型都成立）。代入 $\omega=0$，所有 $e^{-j\cdot 0\cdot n}=1$，求和退化成系数直接相加：

$$H(e^{j0})=\sum_{n=0}^{N-1}h[n]$$

把求和项按 $n$ 与 $N-1-n$ 两两配对（首尾对折）。由反对称性，每一对的和是

$$h[n]+h[N-1-n]=h[n]+\big(-h[n]\big)=0$$

若 $N$ 为奇数，还剩一个与自己配对的中心项 $n=M=\frac{N-1}{2}$，它满足 $h[M]=-h[M]$，两边移项得 $2h[M]=0$，即 $h[M]=0$。所以无论怎么配，总和都是零：

$$H(e^{j0})=0$$

物理上这就是"直流被消灭"（第 4.3.4 节）在有限长滤波器上的必然体现 —— 反对称的系数加起来一定是零，设计者没有任何余地。

在 $\omega=\pi$ 处（这里两种类型分道扬镳）。代入 $\omega=\pi$，用 $e^{-j\pi n}=\big(e^{-j\pi}\big)^{n}=(-1)^{n}$：

$$H(e^{j\pi})=\sum_{n=0}^{N-1}h[n](-1)^{n}$$

还是把 $n$ 与 $N-1-n$ 配对，看这一对贡献多少（第二项用了 $h[N-1-n]=-h[n]$）：

$$h[n](-1)^{n}+h[N-1-n](-1)^{N-1-n}=h[n](-1)^{n}-h[n](-1)^{N-1-n}$$

能不能抵消，全看 $(-1)^{N-1-n}$ 和 $(-1)^{n}$ 是否相等，而这取决于 $N-1$ 的奇偶。先记一个小事实：$(-1)^{-n}=(-1)^{n}$，因为 $(-1)^n$ 只取 $\pm1$，倒数等于自身。于是 $(-1)^{N-1-n}=(-1)^{N-1}\cdot(-1)^{-n}=(-1)^{N-1}\cdot(-1)^{n}$。

  • Type III（$N$ 奇数 ⟹ $N-1$ 偶数 ⟹ $(-1)^{N-1}=+1$）：$(-1)^{N-1-n}=(-1)^{n}$，配对项变成 $h[n](-1)^n-h[n](-1)^n=0$。每一对都抵消，所以 $H(e^{j\pi})=0$ —— 奈奎斯特频率处也被强制为零。
  • Type IV（$N$ 偶数 ⟹ $N-1$ 奇数 ⟹ $(-1)^{N-1}=-1$）：$(-1)^{N-1-n}=-(-1)^{n}$，配对项变成 $h[n](-1)^n+h[n](-1)^n=2h[n](-1)^n$，一般不为零。所以 Type IV 在 $\omega=\pi$ 处不为零，通带可以一直用到奈奎斯特附近。

于是两种类型的取舍就很清楚了：Type III 通带两头都掉，但群延时 $M=\frac{N-1}{2}$ 是整数个采样，对齐方便；Type IV 只掉低频一头，通带更宽，代价是群延时 $\frac{N-1}{2}$ 为半个采样的非整数值，要和原信号对齐还得再加一个分数延时滤波器。实践中 Type III 更常用，代价是必须避开直流和奈奎斯特附近的频率。

7.3.3 代码

import numpy as np
from scipy.signal import lfilter, remez, freqz

# ---- 方法 1：窗函数法（简单直观） ----
from scipy.signal import get_window

def hilbert_fir(M=64, window='hamming'):
    """返回长度 2M+1 的 Type III 希尔伯特变换器，群延时 M 个采样。"""
    n = np.arange(-M, M+1)
    h = np.zeros(2*M+1)
    odd = n % 2 != 0                 # 偶数位置留 0（含 n=0）
    h[odd] = 2.0 / (np.pi * n[odd])
    h *= get_window(window, 2*M+1)   # 加窗，抑制吉布斯振荡
    return h

# ---- 方法 2：等波纹最优法（工程首选，阻带更平） ----
# 通带 0.03~0.47 (归一化到 fs)，避开直流与奈奎斯特
h_opt = remez(65, [0.03, 0.47], [1], type='hilbert', fs=1.0)

# ---- 使用（注意配对延时！） ----
M  = 32
h  = hilbert_fir(M)
xh = lfilter(h, 1.0, x)                              # 输出已延时 M
xd = np.concatenate([np.zeros(M), x])[:len(x)]        # 输入同步延时 M
z  = xd + 1j*xh
env = np.abs(z)

7.3.4 阶数怎么选

下面的交互图可以直接回答这个问题。拖动阶数，看幅度响应在什么频率范围内足够接近 1。至于相位，你会看到一件意外的事 —— 第三个面板无论怎么拖都是一条平直的零线。那不是图没画出来，而是一个值得单独讲的结论，图下方紧接着解释。

为什么相位误差恒等于零

这是本章最值得记住的一个"免费午餐"：你怎么截断、怎么加窗，都不可能把相位弄错。下面推一遍。

第一步 · 写出频率响应，用零相位（居中）下标。

把系数按 $n=-M,\dots,M$ 居中编号（即先不管因果化那步平移，平移的影响放到第五步单独说）。按定义

$$H(e^{j\omega})=\sum_{n=-M}^{M}h[n]\,e^{-j\omega n}$$

第二步 · 把 $n$ 与 $-n$ 配对。这是全部关键。$n=0$ 项为零（$h[0]=0$，第 7.1 节），其余项两两配对，用奇对称 $h[-n]=-h[n]$：

$$H(e^{j\omega})=\sum_{n=1}^{M}\Big(h[n]e^{-j\omega n}+h[-n]e^{+j\omega n}\Big)=\sum_{n=1}^{M}h[n]\Big(e^{-j\omega n}-e^{+j\omega n}\Big)$$

第三步 · 括号里用欧拉反公式。由 $e^{j\theta}-e^{-j\theta}=2j\sin\theta$（第 2.1.2 节），注意这里是反过来的顺序，所以多一个负号：

$$e^{-j\omega n}-e^{+j\omega n}=-\big(e^{+j\omega n}-e^{-j\omega n}\big)=-2j\sin(\omega n)$$

代回：

$$H(e^{j\omega})=-j\underbrace{\left[\,2\sum_{n=1}^{M}h[n]\sin(\omega n)\right]}_{\text{记作}\ A(\omega)}=-j\,A(\omega)$$

第四步 · 看清 $A(\omega)$ 的身份。$h[n]$ 是实数、$\sin(\omega n)$ 是实数，所以 $A(\omega)$ 是一个纯实数函数，虚部一点没有。于是 $H$ 只能落在虚轴上：

$$\arg H(e^{j\omega})=\begin{cases}-\dfrac{\pi}{2}=-90°,&A(\omega)>0\\[6pt]+\dfrac{\pi}{2}=+90°,&A(\omega)<0\end{cases}$$

没有第三种可能。相位要么精确是 $-90°$，要么精确是 $+90°$，绝不会是 $-89.3°$ 这种"接近但不等于"的值。通带内 $A>0$，所以那里恒为 $-90°$，误差精确为零。

第五步 · 说明截断和加窗为什么动摇不了这个结论。整个推导只用了一个前提：$h[n]$ 实且奇对称。而

  • 截断：把 $|n|>M$ 的系数丢掉，是对称地丢（$+n$ 和 $-n$ 同时丢），奇对称保持；
  • 加窗：Hamming/Hann/Blackman 这些窗都是偶对称的（$w[-n]=w[n]$），于是 $$h_w[-n]=h[-n]\,w[-n]=-h[n]\cdot w[n]=-h_w[n]$$ 奇对称仍然保持；
  • 因果化平移：把下标从 $[-M,M]$ 挪到 $[0,2M]$，频域乘一个 $e^{-j\omega M}$，这是线性相位，对应纯粹的 $M$ 个采样延时，不是失真。

三种操作都不破坏前提，所以 $H=-j\,A(\omega)$ 这个结构纹丝不动。它们能改变的只有 $A(\omega)$ 的数值大小 —— 那就是幅度响应 $|H|=|A(\omega)|$，也正是中间那个面板里波动的东西。

这一步的关键直觉：设计一个 FIR 希尔伯特变换器时，你其实只在跟一个实函数 $A(\omega)$ 打交道，目标是让它尽量接近常数 $1$。相位不在设计变量里 —— 它已经被"奇对称"这个结构性约束焊死了。误差的表现形式是"这个频率成分被削弱了"，而不是"被转错了角度"。对照第 4.3.3 节：奇对称的时域系数 ⟺ 纯虚的频率响应 ⟺ 相位是 $\omega$ 的奇函数，这三句话是同一件事，而合法实系统恰好要求相位为奇函数 —— 结构与合法性在这里合二为一。

一个必须配上的警告：上面说的"相位零误差"是滤波器本身的性质，前提是你已经正确扣掉了那 $M$ 个采样的群延时。如果忘了给原信号配对延时（第 7.3.1 节的坑，以及 7.7 节坑 5），$x$ 与 $\hat x$ 之间就会多出一个 $e^{-j\omega M}$ 的相对相位，误差正比于 $\omega$ —— 这时相位是实实在在错的，而且错得很隐蔽（包络看起来"差不多"，瞬时频率却系统性偏移）。所以本图告诉你的是"滤波器不会坑你"，不是"你不会坑自己"。

经验法则

若关心的最低频率是 $f_{\min}$（Hz），采样率 $f_s$，则 FIR 半长大致需要

$$M\ \gtrsim\ \frac{f_s}{2f_{\min}}\times(3\sim5)$$

例：$f_s=10\ \text{kHz}$，想处理到 $50\ \text{Hz}$ 的低频，则 $M\gtrsim 300\sim500$，阶数上千。

这条法则不是凭空来的，它可以从"滤波器必须看得见一个完整周期"这个朴素想法推出来。分三步。

第一步 · 把要求翻译成"滤波器要多长时间的记忆"。希尔伯特变换要对频率 $f_{\min}$ 的成分做出准确的 $90°$ 相移，也就是要把它挪动四分之一周期。一个只能看到 $\pm M$ 个采样的 FIR 滤波器，如果它的记忆窗口还不到四分之一周期，它根本"看不出"这个低频分量正在往哪边走 —— 在它的视野里那就是一条几乎平直的线。所以最低限度是

$$\underbrace{\frac{M}{f_s}}_{\text{单侧记忆时长（秒）}}\ \gtrsim\ \underbrace{\frac{1}{4f_{\min}}}_{\text{四分之一周期}}\qquad\Longrightarrow\qquad M\gtrsim\frac{f_s}{4f_{\min}}$$

第二步 · 认识到"刚好看得见"远远不够。上面得到的是绝对下限，此时滤波器只是勉强分辨出方向，幅度和相位误差都很大。真正决定精度的是截断误差：理想核 $h[n]=\frac{2}{\pi n}$ 按 $1/n$ 慢衰减（第 7.1 节），被丢掉的那条尾巴的能量大致正比于 $\sum_{|n|>M}\frac{1}{n^2}\sim\frac{1}{M}$。误差按 $1/M$ 减小，而不是指数减小 —— 想把误差再降一半，滤波器就得再长一倍。所以要在上面的下限外再乘一个"安全倍数"。

第三步 · 定出那个倍数。工程上通常要求通带内幅度误差 $<1\%$、相位误差 $<1°$，实测下来需要把第一步的下限再放大一个量级左右。把第一步的 $\frac{f_s}{4f_{\min}}$ 改写成 $\frac{f_s}{2f_{\min}}\times\frac12$，再乘上 $6\sim10$ 倍的安全系数，就凑成了常用的写法

$$M\ \gtrsim\ \frac{f_s}{2f_{\min}}\times(3\sim5)$$

其中"$3$"对应"看趋势就行"的粗放场合，"$5$"对应需要定量精度的场合。这个倍数本身是经验值（和窗函数、允许波纹有关），但$\frac{f_s}{f_{\min}}$ 这个主导因子是硬道理：它就是"每个最低频周期占多少个采样点"。

从这条法则能读出什么

真正决定滤波器长度的不是绝对频率，而是相对带宽 $f_{\max}/f_{\min}$。式子里 $f_{\min}$ 在分母上，所以：

  • 把 $f_{\min}$ 从 $200$ Hz 降到 $20$ Hz，$M$ 就要涨 $10$ 倍，延时也涨 $10$ 倍；
  • 而把 $f_{\max}$ 提高一倍，$M$ 几乎不变（法则里根本没有 $f_{\max}$）。

所以低频端才是成本中心。这就引出工程上的标准对策：先把信号整体搬到中频（乘一个复指数 $e^{-j2\pi f_0t}$，即第 7.4 节的下变频），让 $f_{\min}$ 和 $f_{\max}$ 的比值缩小，再用一个短得多的滤波器处理。宁可多一次混频，也不要一个上千阶的宽带 $90°$ 相移器。

7.4 路线三：不做希尔伯特变换（I/Q 正交下变频）

如果已知载波频率 $f_c$（通信系统中总是已知的），有一条更简单的路：直接乘上复载波再低通。

$$z_{\text{baseband}}(t)=\mathrm{LPF}\Big\{x(t)\cdot 2e^{-j2\pi f_ct}\Big\}$$

为什么行得通？把这个乘法老实展开一遍就清楚了。设 $x(t)=A(t)\cos(2\pi f_ct+\theta)$，为了少写字母记 $\varphi(t)=2\pi f_ct+\theta$。

第一步 · 用欧拉反公式把余弦拆成两个复指数（第 2.1.2 节）。这样做的理由是：复指数在相乘时指数直接相加，比三角恒等式好算得多。

$$x(t)=A(t)\cdot\frac{e^{j\varphi}+e^{-j\varphi}}{2}=\frac{A(t)}{2}\Big(e^{j(2\pi f_ct+\theta)}+e^{-j(2\pi f_ct+\theta)}\Big)$$

第二步 · 乘上 $2e^{-j2\pi f_ct}$，逐项相乘。前面的 $2$ 正好抵掉欧拉展开带来的 $\frac{1}{2}$：

$$x(t)\cdot 2e^{-j2\pi f_ct}=\underbrace{A(t)\,e^{j(2\pi f_ct+\theta)}\,e^{-j2\pi f_ct}}_{\text{第一项}}+\underbrace{A(t)\,e^{-j(2\pi f_ct+\theta)}\,e^{-j2\pi f_ct}}_{\text{第二项}}$$

第三步 · 逐项看指数上发生了什么。复指数相乘就是指数相加：

  • 第一项：$j(2\pi f_ct+\theta)+(-j2\pi f_ct)=j\theta$。含 $t$ 的部分精确抵消了，只剩一个常数相位。这一项等于 $A(t)e^{j\theta}$，它的频率内容就是 $A(t)$ 自己的带宽 —— 在 $0$ 附近的低频。
  • 第二项：$-j(2\pi f_ct+\theta)+(-j2\pi f_ct)=-j(4\pi f_ct+\theta)$。两个同号的载波相位叠加，频率翻倍，这一项等于 $A(t)e^{-j(2\pi\cdot 2f_c\,t+\theta)}$，跑到了 $-2f_c$ 处（离基带 $2f_c$ 之远，下面就简称"$2f_c$ 处的高频项"）—— 高频。

合起来：

$$x(t)\cdot 2e^{-j2\pi f_ct}=\underbrace{A(t)e^{j\theta}}_{\text{基带，要的}}\;+\;\underbrace{A(t)e^{-j(4\pi f_ct+\theta)}}_{\text{在}\,2f_c\,\text{处，不要的}}$$

第四步 · 低通滤波。两项在频率轴上离得很远（一个在 $0$ 附近、一个在 $2f_c$ 附近），所以一个截止频率介于两者之间的低通滤波器就能把后者干净地扔掉，剩下

$$z_{\text{baseband}}(t)=A(t)e^{j\theta}$$

取模得包络 $A(t)$，取辐角得相位 $\theta$ —— 和解析信号给出的东西完全一样。

这一步的关键直觉：希尔伯特变换是"不问频率、对所有频率一律转 90°"，所以必须用一个宽带相移器；而 I/Q 下变频是"已经知道载波在哪，干脆把整个频谱搬到零频"，搬过去之后剩下的活只是低通。用已知信息换硬件复杂度，这就是它便宜的原因：实数硬件上它就是两路乘法器（分别乘 $\cos 2\pi f_ct$ 和 $-\sin 2\pi f_ct$，对应复指数的实部与虚部）加两个低通滤波器，而低通滤波器比"在整个宽频带上都精确保持 90°"的相移器好设计太多了。

代价也要说清楚：它要求你事先知道 $f_c$。若 $f_c$ 估偏了 $\Delta f$，第一项的指数就不再抵消干净，变成 $A(t)e^{j(2\pi\Delta f\,t+\theta)}$ —— 包络 $|A(t)|$ 仍然对，但相位会以 $\Delta f$ 的速率漂移，算出的瞬时频率整体偏移 $\Delta f$。这就是通信接收机里必须做载波同步（锁相环、频偏估计）的原因。

方案需要知道 $f_c$？实时？硬件成本典型场合
FFT 法不需要否—（软件）离线数据分析、科研
FIR 希尔伯特器不需要是（有延时）中～高（阶数高）宽带、载波未知

7.5 端点效应

FFT 法有一个内在缺陷：FFT 隐含假设信号是周期的（循环卷积）。如果数据段的首尾数值差很大，等效于在接缝处引入了一个跳变，而希尔伯特变换对跳变极其敏感（例 3.3 中对数发散），于是数据两端会出现虚假的振荡。

7.6 完整的实用流程

import numpy as np
from scipy.signal import hilbert, butter, filtfilt, get_window

def envelope_and_freq(x, fs, band=None, trim=0.08):
    """
    稳健地求包络与瞬时频率。
    x    : 实信号
    fs   : 采样率 (Hz)
    band : (f_lo, f_hi) 带通范围，用于把信号变成单分量；None 则跳过
    trim : 两端各丢弃的比例，抑制端点效应
    """
    x = np.asarray(x, float)
    x = x - x.mean()                            # ① 去直流（第 4.3.4 节）

    if band is not None:                       # ② 带通 → 单分量（第 6.6.1 节）
        b, a = butter(4, [band[0]/(fs/2), band[1]/(fs/2)], btype='band')
        x = filtfilt(b, a, x)                   #    filtfilt 零相位，不引入延时

    n = len(x)                                  # ③ 镜像延拓压制端点效应
    xe = np.concatenate([x[::-1], x, x[::-1]])

    z = hilbert(xe)[n:2*n]                      # ④ 解析信号，取中段

    amp = np.abs(z)                             # ⑤ 瞬时幅度
    dz = np.gradient(z) * fs                    # ⑥ 瞬时频率（微分公式，免解缠）
    fi = np.imag(np.conj(z)*dz) / (np.abs(z)**2 + 1e-20) / (2*np.pi)

    k = int(n*trim)                             # ⑦ 丢弃两端
    sl = slice(k, n-k) if k > 0 else slice(None)
    return amp[sl], fi[sl], np.arange(n)[sl]/fs


# ------------------ 用法示例：包络谱（轴承诊断，第 8.4 节） ------------------

7.7 七个坑（逐条对照检查）

坑 1　把 hilbert(x) 当成 $\hat{x}$

它返回的是解析信号（复数）。要 $\hat{x}$ 必须取 .imag。自检：结果是复数就说明还没取虚部。

坑 2　忘记去直流

直流分量在 $\mathcal{H}$ 下被消灭，但它留在解析信号的实部里，于是 $|z|=\sqrt{(x_{\text{AC}}+\bar x)^2+\hat x^2}$ 被偏置污染，包络整体抬高、瞬时相位失真。永远先减均值。

坑 3　端点效应

数据两端 5%～10% 的结果不可信（第 7.5 节）。对策：多采数据 + 丢两端，或镜像延拓。做包络谱时端点振荡会在频谱里造成宽带底噪，掩盖真实的故障峰。

坑 4　对多分量信号求瞬时频率

见第 6.6.1 节。必须先带通或 EMD 分解。判断方法：看频谱有几个显著峰。

坑 5　FIR 滤波未做配对延时

见第 7.3.1 节的提示框。$x$ 和 $\hat{x}$ 必须时间对齐，否则相位有系统误差。用 filtfilt 做带通预滤波时也要注意：它是零相位的，和 lfilter 混用会引入相对延时。

坑 6　采样率太低（欠采样）

有两个互相独立的理由要求高采样率，很多文献只提第一个：

(a) 相位解缠。瞬时相位每个采样点的增量应远小于 $\pi$，否则解缠会解错方向。这条要求每周期 $\gtrsim$ 8 点。

(b) 数值求导的 $\mathrm{sinc}$ 失真。中心差分使瞬时频率被系统性低估 $\mathrm{sinc}(\omega_i\Delta t)$ 倍（第 6.6.3 节）：

注意：满足 (a) 的 8 点/周期，在 (b) 上仍有 10% 的误差。所以若要定量使用瞬时频率（而不只是看趋势），应做到每周期 20 点以上（$f_s>20f_{\max}$），或按第 6.6.3 节反解修正。奈奎斯特的 $2f_{\max}$ 在这里远远不够。

坑 7　奈奎斯特点与奇偶长度处理错

算法 7.1 步骤 3 里，$N$ 为偶数时 $h[N/2]$ 必须是 1 而不是 2 或 0，$N$ 为奇数时没有奈奎斯特点。写错会导致 $\operatorname{Re}z\neq x$ —— 所以一定要加那句 assert 自检。
