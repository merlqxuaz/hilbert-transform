8.1 通信：单边带调制（SSB）

主线 ①

问题

普通调幅（AM）把基带信号 $m(t)$ 搬到载波上，得到 $m(t)\cos\omega_ct$。它的频谱在 $\pm\omega_c$ 两侧各有一个上边带和一个下边带，占据带宽 $2B$（$B$ 是 $m$ 的带宽）。但因为 $m$ 是实的，上下边带互为镜像 —— 一半的频谱是冗余的，白白浪费了一半带宽和一半功率。

解法

只发一个边带。怎么做？用解析信号。设 $z_m=m+j\hat{m}$（只含正频率），把它搬到 $\omega_c$：

$$z_m(t)\,e^{j\omega_ct}=\big[m(t)+j\hat{m}(t)\big]\big[\cos\omega_ct+j\sin\omega_ct\big]$$

（这里把 $e^{j\omega_ct}$ 用欧拉公式展开成了 $\cos\omega_ct+j\sin\omega_ct$。）把两个括号逐项相乘，共四项，按实虚分开：

$$=\underbrace{m\cos\omega_ct}_{\text{实}\times\text{实}}+\underbrace{j\,m\sin\omega_ct}_{\text{实}\times\text{虚}}+\underbrace{j\,\hat m\cos\omega_ct}_{\text{虚}\times\text{实}}+\underbrace{j^2\,\hat m\sin\omega_ct}_{\text{虚}\times\text{虚}}$$

最后一项用 $j^2=-1$ 变成 $-\hat m\sin\omega_ct$，是实数。归并同类项：

$$z_m(t)\,e^{j\omega_ct}=\underbrace{\Big[m(t)\cos\omega_ct-\hat{m}(t)\sin\omega_ct\Big]}_{\text{实部}}+j\underbrace{\Big[m(t)\sin\omega_ct+\hat{m}(t)\cos\omega_ct\Big]}_{\text{虚部}}$$

取实部就得到一个可以真正发射出去的实信号（天线只能发实信号）：

Hartley 调制器（SSB 生成公式）

$$s_{\text{USB}}(t)=m(t)\cos(\omega_ct)-\hat{m}(t)\sin(\omega_ct)\qquad\text{（上边带）}$$

$$s_{\text{LSB}}(t)=m(t)\cos(\omega_ct)+\hat{m}(t)\sin(\omega_ct)\qquad\text{（下边带）}$$

仅相差一个符号，就决定了留哪半个频谱。

为什么这样就只有一个边带？因为 $z_m$ 的频谱只在 $\omega>0$，乘 $e^{j\omega_ct}$ 把它整体平移到 $\omega>\omega_c$（频移定理，定理 2.2），所以搬过去的只有"上半边"。取实部会补上一个共轭镜像（在 $-\omega_c$ 附近），但那是实信号的必然对称，不额外占带宽。

代码

import numpy as np
from scipy.signal import hilbert

def ssb_modulate(m, fc, fs, sideband='upper'):
    t  = np.arange(len(m)) / fs
    zm = hilbert(m - m.mean())          # 解析信号 m + j*m_hat
    sgn = -1 if sideband == 'upper' else +1
    return zm.real*np.cos(2*np.pi*fc*t) + sgn*zm.imag*np.sin(2*np.pi*fc*t)
    # 等价写法：np.real(zm * np.exp(1j*2*np.pi*fc*t))  ← 上边带
历史与现实

SSB 是业余无线电（HAM）和早期长途电话的主力制式，因为带宽和功率效率都比 AM 高一倍。但实际硬件很少真用希尔伯特变换器 —— 宽带 90° 相移器难做（第 3.7 节），所以模拟时代用"滤波法"（先生成双边带再用陡峭的晶体滤波器切掉一半），数字时代用 I/Q 直接合成（下一节）。希尔伯特变换在这里的价值主要是理论上说清 SSB 到底是什么：它就是解析信号的实部搬移。

8.2 通信：I/Q 正交调制

主线 ①

现代所有的无线通信（WiFi、4G/5G、蓝牙、卫星）都建立在复基带表示上：

$$s(t)=\operatorname{Re}\Big\{\underbrace{\big[I(t)+jQ(t)\big]}_{\text{复基带}}e^{j\omega_ct}\Big\}=I(t)\cos\omega_ct-Q(t)\sin\omega_ct$$

$I$ 叫同相分量（In-phase），$Q$ 叫正交分量（Quadrature）。请对照 8.1 节的 SSB 公式 —— 形式完全一样。区别只是：SSB 里 $Q=\hat{I}$ 被强制绑定（所以只能传一路信息），而 I/Q 调制里 $I$ 和 $Q$ 是两路独立的信息，于是同样带宽能传两倍数据。

QAM、PSK、OFDM 全都是在复平面上安排 $I+jQ$ 的取值点（星座图）。而解析信号的理论保证了：只要 $\omega_c$ 大于基带带宽，接收端就能无失真地把 $I$ 和 $Q$ 分开 —— 这正是 Bedrosian 条件（定理 5.1）的一个直接应用。

8.4 机械故障诊断：包络谱（本章最有代表性的应用）

主线 ②

问题

滚动轴承的滚道上出现一个小剥落（点蚀），每当滚珠滚过这个缺陷，就会产生一次微小的冲击。冲击的重复频率由轴承几何和转速决定，是判断"哪个零件坏了"的关键证据：

特征频率公式指示
BPFO（外圈）$\dfrac{n}{2}f_r\left(1-\dfrac{d}{D}\cos\alpha\right)$外圈滚道故障
BPFI（内圈）$\dfrac{n}{2}f_r\left(1+\dfrac{d}{D}\cos\alpha\right)$内圈滚道故障
BSF（滚珠）$\dfrac{D}{2d}f_r\left[1-\left(\dfrac{d}{D}\cos\alpha\right)^2\right]$滚珠自身故障
FTF（保持架）$\dfrac{1}{2}f_r\left(1-\dfrac{d}{D}\cos\alpha\right)$保持架故障

（$n$ 滚珠数，$f_r$ 转频，$d$ 滚珠直径，$D$ 节径，$\alpha$ 接触角。典型值：BPFO 约为转频的 3～8 倍。）

麻烦在于：这些冲击的能量非常小（早期故障时可能只有整体振动的千分之一），而且它们在普通频谱里几乎看不见。原因是每次冲击都会激起轴承座结构的高频共振（几 kHz 到几十 kHz），能量被摊到了那个宽阔的共振峰里，故障频率本身（几十到几百 Hz）那一带反而被转频、齿轮啮合频率、电机噪声完全淹没。

解法：共振解调（包络分析）

关键洞察是：振动信号是一个"故障冲击序列"调制了"高频共振"的调幅信号。故障信息不在频率里，在包络里。所以：

  1. 带通滤波到共振频带（比如 2–6 kHz），把低频的转频、齿频统统扔掉 —— 这一步同时满足了单分量和窄带条件（第 6.6 节）。
  2. 希尔伯特变换求包络 $A(t)=|z(t)|$。包络的起伏节奏就是冲击的重复节奏。
  3. 对包络做 FFT，得到包络谱（envelope spectrum，也叫解调谱）。故障特征频率及其谐波会在这里清晰地立起来。

代码

import numpy as np
from scipy.signal import hilbert, butter, filtfilt, get_window

def envelope_spectrum(x, fs, band=(2000, 6000)):
    """轴承/齿轮故障诊断的标准流程。返回 (频率轴, 包络谱)。"""
    # ① 带通到共振频带 —— 抛弃低频干扰，满足窄带条件
    b, a = butter(4, [band[0]/(fs/2), band[1]/(fs/2)], btype='band')
    xb = filtfilt(b, a, x - x.mean())

    # ② 希尔伯特包络
    env = np.abs(hilbert(xb))

    # ③ 包络去直流（！）后做 FFT —— 不去直流则 0 Hz 处一根巨峰压平其余
    env = env - env.mean()
    n = len(env)
    w = get_window('hann', n)
    spec = np.abs(np.fft.rfft(env * w)) * 2 / w.sum()
    freq = np.fft.rfftfreq(n, 1/fs)
    return freq, spec

# 诊断：在包络谱里找 BPFO / BPFI / BSF / FTF 及其谐波
freq, spec = envelope_spectrum(vib, fs=20000)
fr = 29.95                                  # 转频 (Hz)，从转速表或键相信号得到
BPFO = 0.5*9*fr*(1 - 0.235*np.cos(np.deg2rad(0)))   # n=9, d/D=0.235
for k in range(1, 5):
    i = np.argmin(abs(freq - k*BPFO))
    print(f"{k}×BPFO = {k*BPFO:6.1f} Hz　幅值 = {spec[i]:.4f}")
为什么这个应用值得单独花一节

它把前七章的知识全部用上了：Bedrosian 条件（为什么要带通）、包络定义（第 6.3 节）、去直流（第 4.3.4 节，两次！信号和包络都要）、端点效应（第 7.5 节）、单分量要求（第 6.6.1 节）。这套流程从 1970 年代（SKF 的 SED 技术、Boeing 的 HFRT）用到今天，是工业界最成熟的希尔伯特变换应用。现代的改进版叫谱峭度（spectral kurtosis）—— 用于自动挑选最佳带通频带，省掉人工选带的经验活。

8.5 地震勘探：瞬时属性

主线 ②

地震勘探中，反射地震记录 $x(t)$ 经处理后要解释成地下地质结构。1979 年 Taner 等人提出用解析信号计算"地震瞬时属性"，至今是标准解释工具：

属性定义地质意义
瞬时振幅（反射强度）$A(t)=|z(t)|$与声阻抗差、含气砂岩相关；用于识别储层
瞬时相位$\phi(t)=\arg z(t)$对振幅不敏感，突出地层连续性与不整合面
瞬时频率$f_i=\dot{\phi}/2\pi$低频异常常与含烃有关（"低频阴影"）
加权平均频率$A^2$ 加权的 $f_i$比裸 $f_i$ 稳健（避开第 6.6.2 节的负频率问题）

之所以有效，是因为地震道近似是"子波（wavelet）× 反射系数序列"的卷积，包络凸显了反射界面的位置和强度，而相位剥掉了振幅的影响，让弱反射的连续层也能看清。

8.6 音频处理：移相、频移与效果器

主线 ①

效果做法为什么需要希尔伯特变换
单边带频移（frequency shifter）$y=\operatorname{Re}\{z(t)e^{j2\pi\Delta f t}\}$把所有频率加上固定 $\Delta f$（而不是乘以倍数），产生非谐的金属音色。用实信号直接乘会同时产生上下两个边带，声音浑浊。
移相器（phaser）级联全通滤波器经典 phaser 其实用的是全通链，但"宽带 90° 相移"的思路来自希尔伯特变换
Dolby / 环绕声编码把声道做 90° 相移再混合使混合后的声道能被解码器分离
包络跟随器（envelope follower）$|z(t)|$比整流+低通更精确、延时更低，用于自动哇音、压缩器侧链
音高检测逐谐波求瞬时频率比零交叉法抗噪，比自相关法时间分辨率高

8.7 生物医学信号：相位同步

主线 ②

脑电（EEG）、脑磁（MEG）研究中一个核心问题是：两个脑区是否在"协同工作"？一个被广泛使用的量化指标是相位锁定值（PLV, Phase Locking Value）：

$$\mathrm{PLV}=\left|\frac{1}{N}\sum_{n=1}^{N}e^{j\left[\phi_1(t_n)-\phi_2(t_n)\right]}\right|\in[0,1]$$

其中 $\phi_1,\phi_2$ 是两路信号的瞬时相位，由希尔伯特变换求得。$\mathrm{PLV}=1$ 表示相位差恒定（完全同步），$\mathrm{PLV}=0$ 表示相位差随机（无同步）。

from scipy.signal import hilbert, butter, filtfilt

def plv(x1, x2, fs, band=(8, 12)):          # 默认 alpha 频段
    b, a = butter(4, [band[0]/(fs/2), band[1]/(fs/2)], btype='band')
    p1 = np.angle(hilbert(filtfilt(b, a, x1)))    # 必须先带通！
    p2 = np.angle(hilbert(filtfilt(b, a, x2)))
    return np.abs(np.mean(np.exp(1j*(p1 - p2))))
这里的坑特别多

PLV 的计算必须先窄带滤波（$\delta,\theta,\alpha,\beta,\gamma$ 中的某一个频段），否则瞬时相位没有意义（第 6.6.1 节）。文献里因为跳过这一步而得出虚假同步结论的例子不少。另外还要注意容积传导问题：两个电极可能只是记录了同一个源，PLV 高但并非真的功能连接 —— 这时要改用对零相位延迟不敏感的指标（如加权相位滞后指数 wPLI）。

其他生物医学应用：心电 R 波检测的包络增强、呼吸信号从心率变异中的包络提取、肌电（EMG）的激活强度估计、脉搏波传导时间的相位估计。

8.8 物理与材料：Kramers–Kronig 关系

主线 ③

这是希尔伯特变换最深刻的应用，它把因果性这个物理原理翻译成了数学约束。

论证

考虑一个线性响应系统（介质对光的响应、电路对电压的响应）。设复响应函数 $\chi(\omega)=\chi'(\omega)+j\chi''(\omega)$。因果性要求：时域响应 $\chi(t)$ 在 $t<0$ 时为零（结果不能先于原因）。

由 Titchmarsh 定理（定理 5.2），"时域单边（因果）"等价于"频域的实部与虚部互为希尔伯特变换"。写成式子就是

$$\chi'(\omega)=\frac{1}{\pi}\,\mathrm{P}\!\!\int_{-\infty}^{\infty}\frac{\chi''(\omega')}{\omega'-\omega}\,\mathrm{d}\omega',\qquad \chi''(\omega)=-\frac{1}{\pi}\,\mathrm{P}\!\!\int_{-\infty}^{\infty}\frac{\chi'(\omega')}{\omega'-\omega}\,\mathrm{d}\omega'$$

但物理实验只能测正频率（$\omega<0$ 没有物理意义），所以教科书里的 K–K 关系总是写成 $\int_0^\infty$ 的形式。这一步"折叠"不是换个写法那么简单，它用掉了一个额外的物理条件，值得推一遍。

推导 · 把 $\int_{-\infty}^{\infty}$ 折成 $\int_0^{\infty}$

第一步 · 找出 $\chi$ 在负频率上的对称性。

时域响应函数 $\chi(t)$ 是实的（实的激励产生实的响应，这是物理要求）。由第 2.5.3 节的共轭对称性：

$$\chi(-\omega)=\overline{\chi(\omega)}$$

把它拆成实虚部，$\chi'(-\omega)+j\chi''(-\omega)=\chi'(\omega)-j\chi''(\omega)$，比较两边：

$$\boxed{\chi'(-\omega)=\chi'(\omega)\ \ (\text{偶})},\qquad \boxed{\chi''(-\omega)=-\chi''(\omega)\ \ (\text{奇})}$$

物理上这两句话是熟悉的：色散（折射率）对正负频率一样，吸收则要反号。这就是那个额外条件。

第二步 · 把积分区间对折。以第一式为例，把 $\int_{-\infty}^{\infty}$ 拆成 $\int_{-\infty}^{0}+\int_{0}^{\infty}$，并对前一半换元 $\omega'\to-\omega'$（换元后区间变回 $0\to\infty$）：

$$\int_{-\infty}^{0}\frac{\chi''(\omega')}{\omega'-\omega}\mathrm{d}\omega' =\int_{0}^{\infty}\frac{\chi''(-\omega')}{-\omega'-\omega}\mathrm{d}\omega' \overset{\chi''\text{奇}}{=}\int_{0}^{\infty}\frac{-\chi''(\omega')}{-(\omega'+\omega)}\mathrm{d}\omega' =\int_{0}^{\infty}\frac{\chi''(\omega')}{\omega'+\omega}\mathrm{d}\omega'$$

第三步 · 两半相加，通分。

$$\chi'(\omega)=\frac{1}{\pi}\,\mathrm{P}\!\!\int_{0}^{\infty}\chi''(\omega')\left[\frac{1}{\omega'-\omega}+\frac{1}{\omega'+\omega}\right]\mathrm{d}\omega'$$

方括号里通分，分母是平方差 $(\omega'-\omega)(\omega'+\omega)=\omega'^2-\omega^2$，分子 $(\omega'+\omega)+(\omega'-\omega)=2\omega'$：

$$\frac{1}{\omega'-\omega}+\frac{1}{\omega'+\omega}=\frac{2\omega'}{\omega'^2-\omega^2}$$

代回即得第一条 K–K 关系。那个 $\frac{2}{\pi}$ 里的 $2$ 和分子上的 $\omega'$，都是这次通分的产物 —— 不是凭空多出来的常数。

第四步 · 第二条同理，只是对称性反过来。这次 $\chi'$ 是偶函数，换元后两项相减而不是相加：

$$\frac{1}{\omega'-\omega}-\frac{1}{\omega'+\omega}=\frac{(\omega'+\omega)-(\omega'-\omega)}{\omega'^2-\omega^2}=\frac{2\omega}{\omega'^2-\omega^2}$$

注意这回分子是 $2\omega$（不带撇），所以 $\omega$ 被提到了积分号外面 —— 这就是第二式为什么多了个前置因子 $\omega$。

Kramers–Kronig 关系（1926–27）

$$\chi'(\omega)=\frac{2}{\pi}\,\mathrm{P}\!\!\int_0^{\infty}\frac{\omega'\,\chi''(\omega')}{\omega'^2-\omega^2}\,\mathrm{d}\omega'$$

$$\chi''(\omega)=-\frac{2\omega}{\pi}\,\mathrm{P}\!\!\int_0^{\infty}\frac{\chi'(\omega')}{\omega'^2-\omega^2}\,\mathrm{d}\omega'$$

式中的 $\mathrm{P}$ 不是装饰：被积函数在 $\omega'=\omega$ 处有一个 $\frac{1}{\omega'-\omega}$ 型的奇点，正是第 2.3 节那种"奇函数型奇性"，只有取主值才有意义。这也是为什么讲 K–K 关系绕不开柯西主值。

物理含义

在光学里，$\chi'$ 对应折射率（光的减速，色散），$\chi''$ 对应吸收系数（光的衰减）。K–K 关系说：

一种材料"吸收多少光"和"让光走多慢"不是两件独立的事。

只要你测出了全频段的吸收谱，折射率谱就被唯一确定了，反之亦然。这在实验上极其有用 —— 比如椭偏仪、反射谱、电化学阻抗谱（EIS）都靠它把不易测的那一半推算出来，或者用它检验测量数据的自洽性（若两者不满足 K–K 关系，说明数据有系统误差或系统非线性）。

回头看第 3 章例 3.4：$\frac{1}{1+t^2}$（洛伦兹吸收线型）和 $\frac{t}{1+t^2}$（色散线型）恰好是一对希尔伯特变换 —— 那就是 K–K 关系最简单的具体实例。它们必须成对出现，因为一个单独的吸收峰在物理上是不可能的。

8.9 控制与电路：Bode 增益-相位关系

主线 ③

同样的道理用在控制系统上。对最小相位系统（无右半平面零极点），$\ln|H(j\omega)|$ 与 $\arg H(j\omega)$ 构成一对希尔伯特变换：

$$\arg H(j\omega_0)=\frac{2\omega_0}{\pi}\,\mathrm{P}\!\!\int_0^{\infty}\frac{\ln|H(j\omega)|-\ln|H(j\omega_0)|}{\omega^2-\omega_0^2}\,\mathrm{d}\omega$$

这个式子是怎么和上一节连上的？关键在"取对数"这一步，值得说清楚。

  1. 先造一个新的"响应函数"。令 $L(\omega)=\ln H(j\omega)$。由复对数的定义， $$L(\omega)=\ln\big|H(j\omega)\big|+j\arg H(j\omega)$$ 也就是说，取对数把"增益"和"相位"变成了同一个复函数的实部与虚部 —— 正好是上一节 K–K 关系需要的形式。这一步是全部技巧所在。
  2. 再问 $L$ 是否满足因果性条件。$H$ 因果保证它在右半平面解析；要让 $\ln H$ 也解析，还必须保证 $H$ 在右半平面没有零点（否则 $\ln 0=-\infty$）。这正是"最小相位"这个前提的来源 —— 它不是额外的技术假设，而是取对数这一步必须付的门票。
  3. 套用 K–K，再折成正频率。对 $L$ 用上一节的推导（$\ln|H|$ 偶、$\arg H$ 奇），就得到上面的式子。那个 $\ln|H(j\omega_0)|$ 的减项是为了让被积函数在奇点 $\omega=\omega_0$ 处相消得更干净（否则主值收敛得很勉强），属于技术性处理，不改变结论。

从公式读出"斜率 × 90°"这条口诀。核函数 $\frac{1}{\omega^2-\omega_0^2}$ 在 $\omega=\omega_0$ 附近取值最大、离得远就迅速衰减，所以积分主要由 $\omega_0$ 附近的增益曲线贡献。若在这一带增益是一条直线（在对数-对数坐标下），即 $\ln|H|=-k\ln\omega+\text{const}$，把它代进去算出的结果是

$$\arg H(j\omega_0)\approx-k\cdot\frac{\pi}{2}$$

其中 $k$ 是以"每十倍频 $\times20$ dB"为单位的斜率。于是有了工程上人人会背的那句：

相位 ≈ 斜率 × 90°　（$-20$ dB/dec ↔ $-90°$；$-40$ dB/dec ↔ $-180°$；$-60$ dB/dec ↔ $-270°$）

后果非常实际：你不能独立地设计幅频特性和相频特性。想让增益在某段频率下降得很陡（比如 $-60$ dB/十倍频），相位就必然会滑到 $-270°$ 附近 —— 那已经越过了 $-180°$ 的稳定边界，系统会振荡。这就是控制工程中著名的"幅频陡度换相位裕度"的取舍，它不是设计技巧的局限，而是因果性的数学后果：想绕过它，只能放弃最小相位（引入右半平面零点），而那会带来逆响应和带宽上限等更糟的问题。

顺带回看第 4.7 节的那个论断：我们给希尔伯特变换器开的规格书是"$|H|\equiv1$（增益完全平坦，斜率 $0$）而相位 $=\mp90°$"。按这条口诀，斜率 $0$ 应当对应相位 $0$ —— 规格书自相矛盾。所以理想希尔伯特变换器必然非因果，这里给出的是第二个独立的证明。

Bode 还由此导出了"面积公式"（Bode 积分定理）：反馈系统的灵敏度函数满足一个守恒律，在某些频段压低干扰，必然在别的频段被抬高 —— "水床效应"。

高维推广

希尔伯特变换是一维的。到了图像（二维）没有"正负频率"的自然划分，直接推广不唯一。工程上常用的两条路：(1) 部分希尔伯特变换，沿某个方向做一维变换；(2) Riesz 变换，一个旋转协变的向量值算子，由它构造的单演信号是解析信号的正确二维类比，给出局部幅度、局部相位和局部方向三个量。想深入图像分析的话，这是下一步要读的东西。
